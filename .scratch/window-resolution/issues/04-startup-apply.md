# 04: 启动强制应用与降级

**What to build:** 每次 DSH 启动时按持久化配置强制应用分辨率：桌面环境（`dsh-app://`）先退出全屏/取消最大化，再 `setBounds`（通道内完成居中与钳制）；浏览器标签页或未注入环境静默跳过并记录一行状态；窗口未就绪时短暂重试。完成后配置 1920×1080 重启 DSH，窗口按该尺寸出现。

**Blocked by:** 02（通道）、03（配置与持久化）

**Status:** resolved

- [ ] `immediately:true` 启动路径在页面加载后应用配置；应用前退出全屏/取消最大化
- [ ] 浏览器环境（非 `dsh-app://`）不尝试改窗口，仅记录"非桌面"状态
- [ ] 通道未注入时不报错，状态可被设置页读取展示
- [ ] 窗口未就绪时短暂重试（有上限与间隔），最终失败不影响正常使用
- [ ] 配置为"关闭"时启动不应用
- [ ] 重复启动/热重载不会叠加定时器或重复应用
