# Triage 标签

本仓库的 issue tracker（当前为 `.scratch/` 本地 markdown，未来可迁 GitHub Issues）使用以下五个 canonical 角色，标签字符串即角色名：

| 角色 | 本文档约定 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（例如"打上 AFK-ready 标签"）时，使用上表对应的字符串。
