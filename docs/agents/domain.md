# Domain Docs

工程技能探索代码库时如何消费本仓库的领域文档。

## 探索前先读

- **`GLOSSARY.md`**（仓库根目录）
- **`docs/adr/`**：读与即将工作的领域相关的 ADR。

单上下文仓库（本仓库属于此类）：根目录一个 `GLOSSARY.md` + `docs/adr/`。

## 使用术语表的词汇

当输出命名领域概念（issue 标题、重构提案、假设、测试名）时，使用 `GLOSSARY.md` 中的术语，不要漂移到术语表明确避免的同义词。

如果需要的概念尚未进术语表，这是一个信号：要么你在发明项目不用的语言（重新考虑），要么存在真实缺口（记下来交给 `/domain-modeling`）。

## 标记 ADR 冲突

当输出与现有 ADR 矛盾时，显式指出而不是静默覆盖：

> _与 ADR-0007 矛盾（事件溯源订单），但值得重开，因为……_
